# Dependencies for a machine that ALREADY has a working CUDA PyTorch
# (e.g. a RunPod "PyTorch" template).  Use with docs/RUNBOOK_GPU.md.
#
# Why this file exists, and why it is not requirements.txt
# --------------------------------------------------------
# Two things must not happen on a GPU image:
#
#   1. torch must not be reinstalled.  It is not listed here, and it is not
#      listed in pyproject.toml either. Accelerate does require PyTorch;
#      pip retains the image's CUDA build when it satisfies that requirement.
#      Check the preflight output after installation before starting a run.
#
#   2. numpy must not be replaced underneath the image's CUDA build. This
#      file therefore leaves numpy untouched, and the runbook installs the
#      package itself with `--no-deps` before installing this list.
#
# The measurement formulas are the same across supported NumPy versions,
# but floating-point results need not be bit-identical. The version used is
# recorded in every run_config.json (`numpy_version`).
